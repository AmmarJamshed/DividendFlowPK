2.1 What is a function?

Simple Word: A function is a reusable recipe card. You give ingredients (inputs). It gives you a dish (output). 
def dividend_income(shares, dividend_per_share):
    """Simple Word: shares × cash per share = cash to you."""
    return shares * dividend_per_share

cash = dividend_income(100, 12.5)
print("Estimated cash:", cash)

def load_prices(rows):
    return rows

def filter_high_yield(rows, min_yield=5):
    out = []
    for r in rows:
        if r["yield"] >= min_yield:
            out.append(r)
    return out

def show_names(rows):
    for r in rows:
        print(r["symbol"], "→", r["yield"], "%")

# ---- main flow (the story of the program) ----
data = [
    {"symbol": "HBL", "yield": 8.1},
    {"symbol": "NESTLE", "yield": 1.8},
    {"symbol": "OGDC", "yield": 7.4},
]
clean = load_prices(data)
picks = filter_high_yield(clean, 5)
show_names(picks)
Simple Word logic rule: Big problem → cut into small jobs → each job becomes one function → main script only calls the jobs in order (like a dividend calendar: find → pay → repeat).

3.4 Missing values

Simple Word: Empty cells are holes. Count holes. Then fill, drop, or flag them — never ignore forever. 
print(df.isna().sum())

# drop rows missing the key field
df = df.dropna(subset=["symbol", "close"])

# or fill a number column with median (middle value)
df["div_yield"] = df["div_yield"].fillna(df["div_yield"].median())

3.5 Clean text and types

df["symbol"] = df["symbol"].astype(str).str.strip().str.upper()
df["date"] = pd.to_datetime(df["date"], errors="coerce")
df["close"] = pd.to_numeric(df["close"], errors="coerce")

4. Statistical tests to check the data

Finale team · IPO · Dividends · Prices · Forecast

“Prices check the past. Forecast looks ahead. Stats tests ask: is this pattern real, or just random noise?”

Simple Word: A statistical test is a fairness check for numbers. It helps you ask: “Does this difference look real, or could luck make it?”

4.1 First: describe the data (no fancy test yet)

import pandas as pd
from scipy import stats

s = df["div_yield"].dropna()
print("mean (average):", s.mean())
print("median (middle):", s.median())
print("std (spread):", s.std())
print("min/max:", s.min(), s.max())
WordSimple Word meaning
MeanTypical average
MedianMiddle value when sorted
Std / varianceHow spread out the numbers are
CorrelationDo two columns move together?
p-value“How surprising is this, if luck alone?” Smaller often means stronger surprise

4.2 Correlation check

# Do price and dividend yield move together?
print(df[["close", "div_yield"]].corr())

r, p = stats.pearsonr(
    df["close"].dropna(),
    df.loc[df["close"].notna(), "div_yield"].dropna()
)
# Better: align clean pairs
pair = df[["close", "div_yield"]].dropna()
r, p = stats.pearsonr(pair["close"], pair["div_yield"])
print("r =", r, "p =", p)
Simple Word: r near +1 = move same way. Near −1 = move opposite. Near 0 = weak link. Always look with a chart too — numbers alone can trick you.

4.3 Normal-ish shape? (Shapiro / visual)

# Small sample normality peek
sample = df["div_yield"].dropna().sample(n=min(50, df["div_yield"].notna().sum()), random_state=42)
stat, p = stats.shapiro(sample)
print("Shapiro stat:", stat, "p:", p)
if p < 0.05:
    print("Simple Word: shape may not be neat bell-curve. Prefer robust checks.")
else:
    print("Simple Word: shape is not screaming 'weird' on this sample.")

4.4 Compare two groups (t-test idea)

Simple Word question: “Do bank yields look different from fertilizer yields — for real?” 
banks = df.loc[df["sector"] == "Banks", "div_yield"].dropna()
fert = df.loc[df["sector"] == "Fertilizer", "div_yield"].dropna()

# Welch t-test (does not force equal spread)
t_stat, p = stats.ttest_ind(banks, fert, equal_var=False)
print("t =", t_stat, "p =", p)
if p < 0.05:
    print("Simple Word: difference looks unlikely from pure luck alone — study why.")
else:
    print("Simple Word: no clear difference on this sample. Do not force a story.")

4.5 Before vs after (paired idea)

# Same symbols: yield this year vs last year
before = df_old["div_yield"]
after = df_new["div_yield"]
t_stat, p = stats.ttest_rel(before, after)
print(t_stat, p)

4.6 Categories: chi-square idea

# Are "high yield" labels linked to a sector?
table = pd.crosstab(df["sector"], df["high_yield_flag"])
chi2, p, dof, expected = stats.chi2_contingency(table)
print("chi2:", chi2, "p:", p, "dof:", dof)
Simple Word: Chi-square checks if category mixes look uneven in a surprising way.

4.7 How to read results without drama

  • p small (often < 0.05): “Surprising under a luck-only story.” Still not automatic truth.
  • p large: “No strong surprise.” Does not prove two things are identical forever.
  • Sample size matters: Tiny data → weak tests. More clean rows → clearer picture.
  • Bad wrangling → bad tests: Garbage in, fancy math out. Clean first.

def clean_data(df):
    df = df.copy()
    df["symbol"] = df["symbol"].astype(str).str.strip().str.upper()
    df["date"] = pd.to_datetime(df["date"], errors="coerce")
    df["close"] = pd.to_numeric(df["close"], errors="coerce")
    df["div_yield"] = pd.to_numeric(df["div_yield"], errors="coerce")
    df = df.dropna(subset=["symbol", "close"])
    return df

def run_checks(df):
    pair = df[["close", "div_yield"]].dropna()
    r, p = stats.pearsonr(pair["close"], pair["div_yield"])
    return {"corr_r": r, "corr_p": p, "n": len(pair)}
